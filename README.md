
# PatchClamp Analysis Pipeline

This repository contains three related MATLAB programs forming a unified analysis pipeline for whole-cell patch-clamp electrophysiology data.

The workflow covers:
- IV / intrinsic property extraction
- Visualization and univariate statistical comparison
- Multivariate population analysis using Linear Discriminant Analysis (LDA)

Each script can be used independently, but they are designed to work together as a coherent analysis pipeline.

---

## Repository Structure

project_root/
- main_IV.m        (Batch IV analysis & feature extraction)
- Plot_IV.m        (Visualization and univariate statistics)
- LDA.m            (Multivariate LDA-based analysis)
- functions/       (Shared helper functions)
- README.md        (This file)

# 1. main_IV.m  
## IV Analysis and Feature Extraction

### Overview
Batch analysis of whole-cell patch-clamp I–V (current–voltage) recordings stored in ABF files.

This MATLAB script extracts passive membrane properties, spike waveform features, and F–I (firing rate–current) characteristics, with interactive quality control and Excel-ready export.

---

### Features

- Batch processing of multiple ABF files
- Flexible folder hierarchy handling (parent / grandparent / great-grandparent)
- Passive membrane property estimation (Rin, Tau, Cm)
- Spike detection and first-spike waveform analysis
- F–I curve construction and slope estimation
- Automatic outlier removal
- Interactive plots for quality control
- Excel-compatible TSV export via clipboard
- Optional saving of figures and MATLAB results

---

### Output Parameters

- Vrest_mV  
  Resting membrane potential (baseline before current step), unit: mV

- Rin_Mohm  
  Input resistance derived from I–V linear fit, unit: MΩ

- Tau_ms  
  Membrane time constant extrapolated to I = 0 pA, unit: ms

- Cm_pF  
  Membrane capacitance calculated as Cm = Tau / Rin, unit: pF

- FI_slope  
  Slope of firing rate vs injected current (F–I curve), unit: spikes/pA

- FirstSpikeLatency_s  
  Latency to first spike in representative sweep, unit: s

- SpikeThreshold_mV  
  Spike threshold estimated by inflection point, unit: mV

- SpikeAmplitude_mV  
  Spike amplitude, unit: mV

- SpikeWidth_sec  
  Spike width, unit: s

- AdaptationIndex  
  Spike-frequency adaptation index

- AHP_mV  
  Afterhyperpolarization amplitude, unit: mV

- Sag  
  Sag during hyperpolarizing current injection

---

### Expected Data Format

- File type: Axon Binary File (.abf)
- Recording mode: Whole-cell current clamp
- Channels:
  - Channel 1: membrane voltage (mV)
  - Channel 2: injected current (pA)
- Structure:
  - Multiple sweeps with step current injections

---

### Requirements

- MATLAB (Signal Processing Toolbox recommended)
- Helper functions located in the functions/ directory

Required helper functions include:
abfload, find_target_I_in_sweep, removeOutliers, findSpikes, analyzeSpike,  
computeAHP, computeSag, import_from_excel_clipboard, getCurrentFigureNumber

---

### Usage

Run in MATLAB:
main_IV

1. Select the top-level folder containing ABF files
2. Specify folder depth
3. Choose ABF file selection method
4. Enter analysis parameters
5. Inspect plots (optional)
6. Results are computed automatically

---

### Export to Excel

At the end of execution:
1. Select variables to export
2. Data are copied to clipboard as TSV
3. Paste directly into Excel or Google Sheets

# 2. Plot_IV.m  
## Visualization and Univariate Statistical Analysis

### Overview
Plot_IV.m visualizes and statistically compares electrophysiological parameters imported from Excel via the clipboard.

It is designed to work seamlessly with outputs generated by main_IV.m.

---

### Key Features

- Direct import from Excel via clipboard
- Flexible selection of group, gender, and batch
- Robust outlier removal using MAD
- Automatic statistical test selection:
  - Two-sample t-test
  - Wilcoxon rank-sum test
  - Optional bootstrap testing
- Effect size calculation (Hedges’ g)
- Scatter plots with jitter
- Multi-parameter comparison in a single figure

---

### Input Data Format

- Spreadsheet copied from Excel
- Row 1: column labels
- Rows 2 and below: data
- Columns may include:
  - Group identifier
  - Gender
  - Batch identifier
  - Numeric parameters (Rin, Tau, Cm, FI slope, etc.)

---

### Typical Use Cases

- Group comparisons of intrinsic electrophysiological properties
- Sex- or batch-controlled analysis
- Rapid QC before formal statistical modeling

# 3. LDA.m  
## Multivariate Analysis Using Linear Discriminant Analysis

### Overview
LDA.m performs multivariate comparison of electrophysiological parameters using Linear Discriminant Analysis (LDA).

It complements univariate analyses by providing a low-dimensional summary of group separability and identifying parameters contributing most strongly to discrimination.

---

### Key Features

- Direct import from Excel via clipboard
- Flexible metadata filtering (group, gender, batch)
- Multiple outlier removal strategies:
  - None
  - MAD per parameter
  - MAD after LDA projection
  - Robust Mahalanobis distance
- Effect size and bootstrap testing
- LDA using MATLAB fitcdiscr
- Visualization of:
  - LDA projections
  - Parameter–axis angles

---

### Interpretation

- Samples are projected onto the discriminant axis
- Group separability is statistically tested
- Contribution of each parameter is quantified by:
  - Normalized discriminant vector
  - Angle between parameter axis and LDA axis
- Smaller angles indicate stronger contribution

---

### Output

If enabled:
- Figures saved as .fig
- Results saved as .mat including:
  - Discriminant vector
  - Parameter angles
  - Metadata labels
